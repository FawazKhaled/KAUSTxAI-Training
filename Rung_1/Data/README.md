# Dataset Setup

This project uses the Students Performance in Exams dataset published on Kaggle by `spscientist`.

Source: [Students Performance in Exams on Kaggle](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

The dataset is used for educational exploratory data analysis. It is not included in this repository because redistribution permission has not been independently verified. The `StudentsPerformance.csv` file is listed in this folder's `.gitignore`.

## Setup

1. Visit the Kaggle dataset page and download the dataset, following Kaggle's terms.
2. Extract `StudentsPerformance.csv` from the downloaded archive.
3. Place the CSV directly in this `Data` folder.

The notebook expects this path when run from `Rung_1`:

`Rung_1/Data/StudentsPerformance.csv`
