# Dataset

This project uses the Students Performance in Exams dataset published on Kaggle by `spscientist`.

Source: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

The dataset is used for educational exploratory data analysis. It is not included in this repository because its redistribution license has not been independently verified.

## Setup

1. Visit the Kaggle dataset page.
2. Download the dataset.
3. Extract `StudentsPerformance.csv`.
4. Place it inside this `Data` folder.
    
The expected path is:

`Rung_1/Data/StudentsPerformance.csv`
